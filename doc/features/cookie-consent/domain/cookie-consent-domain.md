# Cookie Consent Domain

## Purpose

Document that CookieYes consent mode is presentation instrumentation and has no domain model.

## Concepts

- `CookieYesClientDataId`: CookieYes client data identifier, currently `75a44bedb1c4246b0619bb80`.
- `CookieYesScript`: external consent banner script loaded in the Blazor web host.

## Notes

- This feature does not add entities, value objects, aggregates, or domain events.
- This feature must not introduce business logic into Domain or Application layers.

# Releases Use Case

## Primary Flow

1. A user opens the footer quick links.
2. The user selects `Releases`.
3. The application navigates to the releases page.
4. The page shows the latest product snapshot and a concise set of highlight bullets.

## Authoring Flow

1. A developer opens the releases page component.
2. The developer adds a new release entry above the current entry.
3. The developer updates the localized strings for each supported language.
